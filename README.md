# User–Todo Management System using Relational Schema

This project is a backend **User–Todo Management System** developed using **Node.js**, **Express.js**, and **Supabase (PostgreSQL)**.  
It demonstrates **relational database design**, **foreign key constraints**, **cascade delete behavior**, and **complete CRUD operations**.

The application is built as a RESTful API and can be tested using **Postman** or **Thunder Client**. No frontend is required.

---

## 🎯 Objective

The objective of this project is to design and implement a backend system that:

- Uses a **relational schema** with proper foreign key relationships
- Demonstrates **one-to-many relationships** (User → Todos)
- Enforces **CASCADE DELETE** at the database level
- Implements **User Signup** and **User-linked Todo CRUD operations**
- Includes **validations and proper error handling**

---

## 🚀 Tech Stack

- **Node.js**
- **Express.js**
- **Supabase (PostgreSQL)**
- **@supabase/supabase-js**
